# Feature Universe — Cohesive Product Map

**Status:** Structured opportunity catalogue. This is **not** a directive to build everything. Use the priority labels and dependencies below; validated demand can change ordering.

## P0 — a complete first experience
- Student registration, profile, affiliation *claim* vs independently verified affiliation, team invite/role.
- Private project drafts, optional file/media uploads, safe disclosure checklist, edit preview, deliberate Publish.
- Public project pages: cover, demo, sector, problem, solution, stage, team, creator consent, needs, follow/share links.
- Fast public discovery, relevant filters, university/sector pages, search, featured launches (editorial or transparent rules).
- Project milestones: claimed vs supported, draft vs published, activity timeline.
- Non-spam introduction request with founder approval/decline and rate limits.
- Basic report/moderation flow and admin audit visibility; opt-out/depublication.
- Competitions **simple mode** after core showcase works: event page, eligibility, submit existing project, organizer moderation, simple rubric, judged results, feedback.

## P1 — signature participatory experiences
- Pitch Arena pilot: schedule, panel identities, staging, timebox, slides, Q&A, independent scoring, attendance, replay consent decisions.
- Challenge Exchange: sponsor verification, transparent rules/IP, applications, sealed submissions until deadline where relevant, award/contract stages.
- Founder milestones: project roadmap, update/follow notifications, meaningful progress challenges.
- Professional mentor directory / office hours; availability, relevance, verified status, feedback.
- University showcase tools: official organization page, authorized organizer console, cohort and event administration.
- Builder discovery: cofounder/collaborator matching, role postings, consented introductions, team agreements.
- Founder project passport & verified achievement issuance, corrections/revocations.

## P2 — compounding ecosystem tools
- Multi-stage competitions, inter-university leagues, transparent categories/season histories, conflict-of-interest and appeals handling.
- Pitch Studio: rehearsal and permission-aware AI deck coaching; approved recorded snippets/annotations.
- Hybrid expos / virtual booths / event rooms / scheduled expert roundtables; optional livestreams.
- AI recommendation assistant for opportunities, gaps in project evidence, founder learning plan.
- RAG / semantic search on explicitly public and authorized documents; institution discovery analytics.
- Industry research-to-pilot / testing network, structured evaluations and licensing introductions.
- Project compare and sector-specific technical maturity/impact lenses with explanations.

## P3 — conditional / long horizon
- Project DNA + confidence-based innovation indicators; national/sector indices with normalizations and anti-gaming rules.
- University portfolio licensing and configurable research commercialization workflows.
- Research asset marketplaces for patents, CAD files, software components, models, datasets and APIs (rights-checked).
- Authorized investor data rooms, permissions, due-diligence trails, deal management and e-signatures.
- Institution-sponsored procurement challenge pathways; post-pilot outcome measurement.
- Geographic ecosystem explorer/innovation map, opt-in locations.
- Open API with explicit data licenses; aggregate public research reports.
- Equities/cap tables/capital products only with counsel, licensed partners and relevant authorizations; not assumed feature scope.

## Design hooks that make the experience feel alive
- Rich card includes real prototype media, project stage, university affiliation *status*, recent meaningful milestone, stated need and clear next action.
- Personal home says **what matters today**: relevant challenge deadlines, followed startup updates, invitations, upcoming pitches, pending actions—not artificial engagement scores.
- Project page is flagship. Reserve strong visual space for authentic demos. Make outcomes and progress more prominent than generic descriptions.
- Competition page tells user instantly: can I enter, by when, rules/prizes, what's judged, next stage, how to appeal.
- Pitch event is tightly integrated into the permanent project profile; attending should lead to authorized collaboration.
- Enterprise challenge page makes sponsor identity, rights and prize/pilot terms impossible to miss.
- Student project can exist as **research/prototype** before any company incorporation.

## Anti-patterns
- Unauthenticated page exposes unpublished drawings, papers or draft descriptions.
- Forced ID verification for casual public visitors.
- Unexplained AI scores, fake 'market prices', leaderboards based on likes or vanity views.
- Destructive project overwrites instead of immutable provenance events.
- Fake university partner badges, real students represented by fabricated photos/claims.
- Livestreaming IP-sensitive content without deliberate audience and recording controls.
- Competition judges changing criteria after submissions without fair notice.
- Sponsor harvesting proposal IP through opaque challenge terms.

## Feature definition of done
User journey works with seeded **fictional** content, appropriate auth/policy boundaries, empty/loading/error/success states, automated tests for key authorization transitions, accessibility review, responsive layouts and documented observability/rollback for meaningful failures.


## Founder-confirmed feature expansion — must not be omitted
- **Exchange-grade discovery and insight:** sector market explorer, project watchlists, meaningful progress charts, source-labeled performance views, clearly scoped rising/top-performing categories, reproducible ranking methodology and comparisons (see `EXCHANGE-EXPERIENCE-AND-RANKINGS-PRD.md`).
- **Universal participant onboarding:** one account, multiple safely authorized roles; student, team/founder, expert, judge, university, investor, sponsor, lab operator, equipment/materials vendor, manufacturer and pilot host.
- **Resource and facilities marketplace:** labs, machines/equipment, materials, fabrication services, in-kind support, quote and booking requests, availability and moderated verified provider profiles (see `MULTI-ROLE-ONBOARDING-AND-LAB-EXCHANGE-PRD.md`).
- **Future market-readiness:** investment discovery, cap-table preparatory structures, and fully inactive potential authorized partner-led primary share purchase / secondary share trading pathways, activated only upon separate legal approval and integration.

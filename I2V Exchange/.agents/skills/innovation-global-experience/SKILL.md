# International Experience and Brand-Craft Workflow

1. Read the latest design specification and founder decisions; do not finalize an un-cleared brand, name, logo or institution partnership.
2. Establish consistent navigation for Discover, Arena, Network, Workspace and Exchange; account for screen-size differences, institutional workflows and mobile-first entry.
3. Build a cohesive semantic color system and type scale with branded, purposeful variation: warm light surfaces, deep ink, cobalt signal and restrained live-event accent; avoid generic AI dashboard tropes.
4. Localize with externalized strings, proper pluralization, formats, locale-sensitive dates, DST-aware scheduling, currencies with ISO codes, and adaptable names/addresses; avoid claiming exchange-rate conversions without sources.
5. Ensure 360px screen, large text, voiceover, keyboard, reduced motion, contrast, RTL readiness and responsive web; test real copy truncation, slow networks, interrupted uploads and media controls.
6. Use respectful real-world imagery only with rights and consent; demo content must be unmistakably fictional and diverse by discipline, geography and project maturity.
7. Set international recognition through the *actual creator work*, searchable project pages, credible institutions, consistent event identity and shareable outcomes rather than decorative gimmicks.
8. Verify mobile screenshots and web states for discoverability, navigation, typography, content hierarchy and accessibility before signoff.

Definition of done: a documented design review with evidence from representative screen sizes and locales and a prioritized issue list.

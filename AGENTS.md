The application monorepo lives in `I2V Exchange/`. Read and follow `I2V Exchange/AGENTS.md`, `CURRENT_FOUNDER_DECISIONS.md`, and `CODEX_MASTER_DIRECTIVE.md` there before engineering changes. The current working name is I2V Exchange; older provisional naming and web-only proposals are superseded by the current founder mandate.

Preserve the specifications and the fifteen custom skills in `I2V Exchange/.agents/skills/`. Run commands from `I2V Exchange/`; see `GETTING_STARTED.md`, `TESTING_STATUS.md`, `NEXT_ACTIONS.md`, and `docs/adr/0001-application-foundation.md` for the implemented baseline and remaining work. Do not treat local development security or fictional examples as production verification.

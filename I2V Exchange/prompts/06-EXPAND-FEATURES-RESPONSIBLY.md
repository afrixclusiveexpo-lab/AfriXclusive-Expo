# Copy into Codex — Propose Distinctive Product Features

Use `$innovation-product`. Read `docs/product/DIFFERENTIATORS-AND-EXPERIMENTS.md` and `FEATURE-UNIVERSE.md`. Suggest **at most five** high-impact ideas or meaningful refinements that improve the actual value for university innovators, judges, sponsors or institutions. Reject gimmicks and copied features without a reason to win.

For each: unmet user job, user delight moment, competing solutions, how one project identity is reused, rights/privacy implications, build complexity, minimum test, pilot metric and what must be removed/delayed to make room. Rank by credible improvement in project exposure, real collaborations, project progress and partner interest.

Make no claims of unique invention without research. Do not start implementing until a specific feature is selected.
